# NextE&M IBS-인도 사업 검토본

KOICA 포용적 비즈니스 프로그램(IBS) 자유주제 — 인도 사업 신청서 검토용 단일 페이지.

세 탭으로 구성:
1. 사고 틀 (검토용)
2. 분석 자료 (회사자료 매핑)
3. 사업 정체성 답변 (객관식 입력 + 자동 저장 + MD/JSON 다운로드)

## 접근

GitHub Pages 발급 URL을 모바일·PC 브라우저에서 직접 엽니다. 답변 입력은 브라우저 LocalStorage에 자동 저장되며, 작성을 마치면 「답변 저장(HTML)」 또는 MD·JSON 다운로드 버튼으로 정리본을 받습니다. 회수는 다운로드 파일을 카톡·메일로 회신하는 방식입니다.
